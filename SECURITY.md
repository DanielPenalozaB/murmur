# Security

Murmur records meetings, so privacy problems count as security problems: audio or
transcripts leaving the Mac without the user choosing a cloud model, API keys stored
or logged in plain text, or files written outside the user's folders.

Please report them privately through
[GitHub security advisories](https://github.com/DanielPenalozaB/murmur/security/advisories/new),
not in a public issue. You'll get a reply within a week.
